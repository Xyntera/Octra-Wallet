Wallet features

Built for day-to-day Octra usage.

Public and bulk transfers

Send OCT normally or prepare up to five recipients with sequential nonces.

Private balance flows

Register PVAC, encrypt public OCT, decrypt private OCT, and claim stealth transfers.

Scoped history

OctraScan-backed history is scoped to the active wallet with explorer links.

Multi-wallet management

Create, import, watch-only, rename, export, and switch wallets locally.

Custom tokens

Import token contracts, view balances, remove tokens, and send token transfers.

Transaction confirmation

PIN and biometric checks protect transaction-changing operations.

Architecture

No local server. No hosted wallet core.

Flutter owns the interface. Native libraries own PVAC-heavy wallet-core work. The UI stays responsive because long crypto calls run outside the main isolate.
